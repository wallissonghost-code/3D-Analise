# 3D-Analise

Repositório base limpo e reutilizável para novos protótipos e ferramentas web.

## Estrutura
- `index.html` — entrada do projeto
- `styles.css` — estilos globais
- `app.js` — lógica inicial
- `.github/workflows/pages.yml` — deploy no GitHub Pages

## Uso
Edite os três arquivos principais para iniciar um novo projeto. O histórico anterior continua recuperável pelo Git.
